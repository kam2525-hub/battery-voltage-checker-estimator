# 乾電池チェッカー・残量測り分けシミュレーター

リモコンや時計で動かなくなった乾電池の電圧と残量を予測し、まだ使える機器への再利用を提案するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/battery-voltage-checker-estimator/）。
2. 画面の指示に従って操作します。
